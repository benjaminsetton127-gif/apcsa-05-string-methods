# Peer Code Review: five parts

Copy this file to `reviews/review-of-NAME.md` (NAME = your partner's first name) and fill it in. Spend about 10 minutes. Name a line number. Be kind and be specific.

**Reviewing:** (partner's GitHub username and file)
**Reviewer:** (you)

## 1. Does it run?
Yes or no. If no, what is the first error message?

## 2. One good thing
Name something real that works. Use a line number.
Starter: "Line __: your ______ is clear because ______."

## 3. One confusion
Something you had to read twice. Use a line number.
Starter: "Line __: I was not sure what ______ means."

## 4. One suggestion
One change that would make it better, and why.
Starter: "You could ______ because ______."

## 5. One question
A curious question about how it works.
Starter: "What would happen if the email had no @?"
